这是 Braindecode 增强版混淆矩阵，各部分含义如下：

## 1. 单元格内容（每个格子三行）

```
412        ← 原始计数：预测为 Left Hand，真实也是 Left Hand 的样本数
15.9%      ← 占总数比例：412 / 总样本数
66.6% (F)  ← F1 分数（仅对角线）：精确率和召回率的调和平均
```

- **对角线** (左上到右下)：预测正确，显示 `数 + 比例 + F1`
- **非对角线**：预测错误，显示 `数 + 比例`

## 2. 坐标标签

| 位置 | 含义 |
|------|------|
| Y 轴 (左侧) | **Predictions** 预测类别 |
| X 轴 (底部) | **Targets** 真实类别 |

> 注意：代码中 `confusion_mat.T` 转置了矩阵，所以行=预测，列=真实（与标准 sklearn 相反）

## 3. 右侧 Precision 列

每行的精确率：

```
Left Hand 行: 69.83%  ← 预测为 Left Hand 的样本中，有 69.83% 是真的 Left Hand
Right Hand 行: 72.87%
Feet 行: 74.56%
Tongue 行: 80.28%
```

**公式**：`TP / (TP + FP)`

## 4. 底部 Recall 行

每列的召回率：

```
Left Hand 列: 63.58%  ← 真实是 Left Hand 的样本中，有 63.58% 被正确识别
Right Hand 列: 76.70%
Feet 列: 85.96%
Tongue 列: 70.99%
```

**公式**：`TP / (TP + FN)`

## 5. 右下角总体指标

```
74.31%  ← 整体准确率 (Accuracy)
```

**公式**：`正确预测数 / 总样本数`

## 6. F1 分数（对角线）

例如 `79.9% (F)` 表示 Feet 类别的 F1 分数：

$$F1 = 2 \times \frac{Precision \times Recall}{Precision + Recall}$$

这是精确率和召回率的调和平均，综合反映分类性能。
