## "被试"是指 **subject**，不是 run

### 层级关系

```
Dataset
  └── Subject (被试) ← 你问的这个
        └── Session (实验阶段)
              └── Run (一次采集)
                    └── Trial (单个试次)
                          └── Window (训练窗口)
```

### 具体示例（BNCI2014_001）

```
BNCI2014_001
  └── Subject 1 (被试1, 第1个受试者)
        ├── Session 0
        │     ├── Run 0 (一次采集, 6个trial)
        │     ├── Run 1
        │     ├── Run 2
        │     ├── Run 3
        │     ├── Run 4
        │     └── Run 5
        └── Session 1
              ├── Run 0
              └── ...
  └── Subject 2 (被试2)
  └── ...
  └── Subject 9 (被试9)
```

### 术语对应

| 中文 | 英文 | 含义 |
|------|------|------|
| **被试** | **Subject** | 一个参与实验的人 |
| 实验阶段 | Session | 同一次实验的不同阶段 |
| 次/轮 | Run | 一次连续的采集 |
| 试次 | Trial | 单个刺激-反应事件 |

### 代码中的体现

```python
# 加载指定被试
dataset = MOABBDataset("BNCI2014_001", subject_ids=[1, 2, 3])

# dataset 的结构
dataset.datasets  # 9个被试
dataset.datasets[0]  # 第1个被试 (Subject 1)
dataset.datasets[0].raw  # 该被试的全部原始数据
```

### 简单记忆

一个**被试（subject）**就是一个**人**，他在实验中可能参加多个 session、每个 session 有多个 run、每个 run 有多个 trial。
